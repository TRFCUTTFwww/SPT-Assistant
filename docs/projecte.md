## 转换桌

按 **F10**，或 **右 Shift → 趣味功能 → ProjectE** 打开。大厅需要先打开角色库存，让原生库存控制器就绪；可直接在角色库存上打开转换桌。战局使用当前存活 PMC 的真实背包、弹挂、口袋，大厅额外包含仓库。Scav 不使用 PMC 的 EMC 钱包。

GUI 使用 MC 式像素边框、凹槽、物品格、按钮和 ProjectE 原版转换桌法阵、转换板贴图；物品显示实际图标与堆叠数量。左右两侧分别是库存和已学物品，均支持搜索、分页。输入数量后，左侧“消耗并学习”移除实际物品并入账，右侧“取出物品”花费 EMC 创建独立物品，并检查原生格子空间和过滤器。取出物品不带 FIR 标记。

**1 卢布 = 1 EMC**；卢布现金默认已学，可以直接存入、取出。其他原版和 MOD 物品按运行中服务端的手册卢布参考价计价，有有效价格的物品才能转换。耐久、医疗资源、食物资源和有限次数钥匙按剩余比例折价，向下取整；取出为默认状态。任务物品和没有价格的物品不可消耗。带内容物的容器、装弹弹匣、带附件武器需要先清空或拆卸，防止连带销毁内部物品；取出武器本体后需要按塔科夫原生规则装配附件。

EMC 和已学模板保存在当前服务端存档的 `localProjectETransmutation` 扩展中。每个转换有独立流水号，重复请求不会重复扣款或消耗；失败后撤回服务端账目与库存，保留未确认流水以便恢复。大厅由服务端同时保存物品与余额，再镜像到客户端；战局由原生库存控制器修改物品，EMC 单独保存。未确认请求会阻止该角色继续转换，使用“恢复流水”核对、撤回；热更新等待网络操作结束。客户端未确认流水保存在 `UniversalModHost/state/projecte/data/pending-<角色 ID>.json`。

音效使用 ProjectE 原版 `tock`（界面操作）、`pecharge`（首次学习）、`petransmute`（消耗转换）、`chargetick`（取出）、`peuncharge`（失败撤回）。OGG 原文件与解码后的 PCM WAV 一并提供，运行时创建并复用 AudioClip。武器保留塔科夫原生挥砍、命中声音。

## 底部 MC HUD

默认开启，可在趣味功能的 ProjectE 页面调节显示、大小、音量和转换桌快捷键。配置文件为 `BepInEx/config/local.projecte.cfg`。

- 十颗爱心：实际总生命值占当前最大生命值的比例，支持半心。
- 十个鸡腿：实际能量比例，支持半格。
- 十个蓝色水滴：实际水分比例，参考 Tough As Nails 的水滴显示思路，自绘像素图标，未复制其素材。
- 等级与绿色经验条：当前塔科夫等级，按 EFT 经验表计算当前等级到下一级的进度；满级为满条。
- 九格快捷栏：读取原生数字 1–9 绑定的真实物品，显示实际图标、数量和当前手持高亮；切换和使用沿用塔科夫原本的数字键操作及绑定规则。原生 0 键仍可使用，此九格中不显示。不是完整替换塔科夫背包系统。

HUD 仅在战局中显示，背包打开时隐藏。数值每秒读取十次，像素图标使用缓存纹理，避免逐像素绘制导致大量每帧调用。转换桌只在打开、手动刷新和操作后扫描库存；不在后台反复遍历仓库。

## 转换桌

按 **F10**，或 **右 Shift → 趣味功能 → ProjectE** 打开。大厅需要先打开角色库存，让原生库存控制器就绪；可直接在角色库存上打开转换桌。战局使用当前存活 PMC 的真实背包、弹挂、口袋，大厅额外包含仓库。Scav 不使用 PMC 的 EMC 钱包。

1.0.3 使用原版完整 228×196 转化桌底图，按同一提交 `TransmutationContainer.java` 的坐标绘制双法阵：左侧八个快捷输入位来自当前库存页，右侧十六个输出位显示已学物品，下方为九列、四行的库存分页。贴图以三倍像素绘制，小屏幕整体缩小；不再截取局部法阵放在两张列表之间。底部库存筛选和上方法阵搜索互相独立。

点击下方库存或左侧快捷输入位，在右侧设置数量，再点“消耗并学习”（也可点火焰消耗槽）；选择右侧法阵后，操作面板切换为“取出物品”。只有当前选择对应的操作可执行，按钮同时校验已连接、任务物品、内容物、剩余资源、数量、堆叠上限、余额和待恢复转换。数量支持加减及最大值，取出上限按余额与原生堆叠计算；空间和过滤器仍在发送请求前检查。右侧法阵默认显示全部已学物品，买不起的物品变暗，可切换仅显示买得起的物品。取出物品不带 FIR 标记。底图的叉号用于清除选择，不会销毁物品或遗忘知识。

首次钱包为零，默认只学会卢布：先消耗库存中的卢布或其他可转换物品，再取出已学物品。无库存会话时仍显示窗口和指引；打开 PMC 角色库存后可重新连接。连接加载期间可关闭窗口，真正进行库存转换时等待操作完成。物品数量变化会刷新对应物品以及大厅仓库；打开窗口时每秒刷新一次库存快照。

**1 卢布 = 1 EMC**；卢布现金默认已学，可以直接存入、取出。其他原版和 MOD 物品按运行中服务端的手册卢布参考价计价，有有效价格的物品才能转换。耐久、医疗资源、食物资源和有限次数钥匙按剩余比例折价，向下取整；取出为默认状态。任务物品和没有价格的物品不可消耗。带内容物的容器、装弹弹匣、带附件武器需要先清空或拆卸，防止连带销毁内部物品；取出武器本体后需要按塔科夫原生规则装配附件。

EMC 和已学模板保存在当前服务端存档的 `localProjectETransmutation` 扩展中。每个转换有独立流水号，重复请求不会重复扣款或消耗；失败后撤回服务端账目与库存，保留未确认流水以便恢复。大厅由服务端同时保存物品与余额，再镜像到客户端；战局由原生库存控制器修改物品，EMC 单独保存。未确认请求会阻止该角色继续转换，使用“恢复流水”核对、撤回；热更新等待网络操作结束。客户端未确认流水保存在 `UniversalModHost/state/projecte/data/pending-<角色 ID>.json`。

音效使用 ProjectE 原版 `tock`（界面操作）、`pecharge`（首次学习）、`petransmute`（消耗转换）、`chargetick`（取出）、`peuncharge`（失败撤回）。OGG 原文件与解码后的 PCM WAV 一并提供，运行时创建并复用 AudioClip。武器保留塔科夫原生挥砍、命中声音。

## 底部 MC HUD

默认开启，可在趣味功能的 ProjectE 页面调节显示、大小、音量和转换桌快捷键。配置文件为 `BepInEx/config/local.projecte.cfg`。

- 十颗爱心：使用 Minecraft Java 1.8.9 原版容器、满心、半心贴图，实际总生命值占当前最大生命值的比例。
- 十个鸡腿：使用同版本原版饥饿值贴图，实际能量比例，从右向左填充，支持半格。
- 等级与绿色经验条：使用原版 182×5 经验条与像素字体，绿色等级带原版黑色轮廓。显示当前塔科夫等级，按 EFT 经验表计算当前等级到下一级的进度；满级为满条。
- 快捷栏：直接读取 `CommonUI.EftBattleUIScreen.QuickAccessPanel` 的实际 `QuickSlotView`，按界面从左到右排列，包含原生启用的固定武器槽、G/V 与数字 1–0 槽。槽位数随原生界面变化，不再固定九格。物品、原生图标及其色调、按键文本、堆叠/资源数字、手持选中状态每帧跟随原生界面；快捷栏显示/隐藏及淡入淡出也跟随原生面板。沿用原生按键操作。

爱心、鸡腿、经验条、快捷栏底图和选中框来自 Mojang 官方 1.8.9 客户端原始 `icons.png`、`widgets.png`，数字来自原始 `ascii.png`。按原版 9×9 状态图标、8 像素间距、20 像素格距和 24×22 选中框绘制，HUD 使用整数屏幕像素倍率与 Point 采样。九格底图逐像素保留；塔科夫超过九格时以原图内部格纹扩展，保留两端边框。素材来源、客户端 SHA-1 与 PNG SHA-256 记录于 `mc-hud-provenance.json`；Minecraft 美术版权属于 Mojang/Microsoft，不适用 ProjectE MIT 许可。

HUD 仅在战局中显示，背包打开时隐藏。生存数值每秒读取十次，原生快捷栏内容每帧读取，组件列表每秒缓存一次。使用图集裁切和缓存纹理，避免逐像素绘制；不再为快捷栏独立生成或缓存原版物品图标。原生面板来源与槽位快照写入 `state/projecte/data/hud-status.json`，仅作本机诊断。转化桌在首次可用库存会话中执行一次只读预检，随后在打开、刷新和操作后更新，窗口打开期间每秒刷新库存。连接及交易结果摘要写入 `state/projecte/data/table-status.json`，不包含角色或物品实例 ID。

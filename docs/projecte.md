# ProjectE / 像素剑 — 内置 SPT Assistant 2.3

适用 EFT 48558 / SPT 5.0。独立商人 **Developer** 使用用户提供的原图，集中出售公开 MOD 物品，不出售原版物品；保留附件组合和交换条件，从原版商人移走这些 MOD 商品。

## 道具与操作

- **F10** 打开转换桌；库存和已学物品上下滚动。便携转化桌手持右键也可打开。移除了底部常驻提示。
- 无线访问终端仅在手持并右键打开时连接原生仓库；关闭界面或切走终端立即撤销访问，待未确认保存完成后释放本地快照。普通 Tab 不再沿用之前的仓库连接，每次显式打开重新读取版本。仓库代码、接口和流水位于 ProjectE 内部，不依赖辅助 MOD。保存使用版本校验，丢失响应可重试，旧快照不能覆盖新库存。
- 不死图腾在身上携带即可生效，仓库里的无效。抵挡一次致命伤并消耗一个，清除负面效果、恢复部位血量，附带恢复和抗火。手中是枪时保留枪；手持被消耗的图腾时才收起它。
- 身之宝石每秒需要时花 64 EMC 恢复 2 能量；灵魂宝石花 64 EMC 恢复合计 2 生命，分配给未损毁部位。生命宝石按实际需要分别支付并提供两种效果，不与前两种重复叠加。
- 时间洪流怀表按 0/1/2 档，每秒消耗 20/30/40 EMC，将 8 米内本地 AI 的水平移动降至 25%/16%/12%。这是 EFT 移植效果，不修改全局时间或玩家速度。
- 修复护符每秒恢复 1 耐久，最多到装备当前最大耐久，不修复永久损失的上限。
- 十六色炼金术之袋，外部 1×1、内部 13×8。**每个物品实例独立，包括同色袋子**；禁止袋子互套。
- 量子剑使用 Modern Industrialization 原始贴图，在原生刀刃碰撞命中本地 AI 的人物区域时、护甲结算前直接击杀；环境碰撞保持原生行为。原生兜底伤害使用有限数值，避免无穷大破坏计算。没有 PE 充能功能。

暗物质剑、红物质剑、红物质拳剑：**R** 充能、**Shift+R** 降档、**G** 范围技能，后两种按 **M** 切换敌对 / 全部 AI。最高 2/3/4 档，每档 2.5 米；依照原模组，用角色碰撞盒向外扩展并检测目标碰撞盒，最高分别 5/7.5/10 米。只影响本地 AI，不攻击自身和真人。技能触发原生挥刀，同次动画碰撞不重复造成伤害。三把 PE 剑和量子剑均为 1×2 格。

平板和终端缩小了网格、厚度，调整手持朝向与距离。其余被动道具沿用普通物品展示。

## 转换与 HUD

1 卢布 = 1 EMC，其他物品依照服务端手册参考价，按耐久和资源比例折价。任务物品、无价格物品、带内容物容器和带附件武器不能直接消耗。取出不带 FIR。钱包、知识、收据按 PMC 保存；转换、撤回和重试有幂等保护，待恢复操作阻止新转换与热卸载。

消耗物品换 EMC 的音量默认降到原来的 35%，并合并 180 毫秒内重复声音；其他音效保持原有增益。可在 ProjectE 设置中调整。

HUD 使用 MC 原始爱心、饥饿、经验和快捷栏素材，口渴使用 Thirst Mod 原始水滴图集。显示 EFT 实际数值；低值间歇抖动，空值持续剧烈抖动，健康状态稳定。抖动按 20 Hz 确定性计算，不使用游戏随机数。背包打开时隐藏 HUD。

## 2.3 安装与迁移

MC 客户端和服务端已内置于辅助 MOD。使用辅助 2.3 完整安装包，关闭客户端和服务端后运行安装器。旧 `atm-swords`、`projecte` 独立加载模块和旧 MC 服务端目录会备份停用；辅助本体和其他独立模块仍可重载。不要再运行旧的独立 MC 安装脚本。

MC HUD 总开关、爱心、饱食度、口渴、经验和物品快捷栏在 **趣味功能 → ProjectE** 分别控制。沿用 `local.projecte.cfg` 与 `local.allthemodium.swords.cfg`。钱包、知识和终端库存保存在原角色存档；未完成转换操作日志迁移到辅助 MC 数据目录。服务端资源、状态和终端备份位于 `SPT_Runtime/user/mods/LocalGearMail/Minecraft`。客户端不再定时检测独立 MC 逻辑模块或提供 F9 子模块刷新。

辅助 MOD 的 **人物与移动 → 部位血量** 分别修改七个部位当前值 / 上限；**开发工具 → 右键菜单** 保留独立页面。

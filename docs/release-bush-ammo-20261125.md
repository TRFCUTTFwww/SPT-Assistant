# 草丛移动与膛内弹药显示

- 人物 → 移动与穿墙新增「草丛不减速」开关，默认关闭。
- 开启时取消本地玩家的草丛速度限制和草丛冲刺限制；关闭或卸载后重新计算原生限制。
- 保留草丛的进出计数、声音及其他障碍物的移动限制。
- 弹夹信息中的「膛内 1」改为实际膛内弹药的完整名称与规格，空膛显示「空膛」。转轮读取当前弹巢，已击发的弹壳不作为实弹。
- 弹药名称过长时自动换行。

修正：实机草丛的 `Swamp_collider` 与树木声音组件分开，原先的父子组件识别漏掉了该碰撞体。改为读取原生草丛区域计数和障碍物减速标记。

「沼泽不减速」为同页的独立开关，默认关闭；草丛与沼泽按原生草丛区域状态分别使用各自的开关。

# 2.0.4

- 准星指向存活 AI 时，左侧容器详情区显示 AI 当前 Buff／异常状态，包括实时强度、作用部位、状态和剩余时间；针剂子效果显示各自的数值、实际部位、延迟与剩余时间，省略已结束或未触发的子效果。
- 默认开启“镜头与画面 → 人物显示 → 准星 AI Buff 信息”；不依赖人物 ESP 或物品 ESP 开关。每 0.1 秒读取一次，倍率镜使用实际镜内相机。移开准星、遇到遮挡、目标死亡、菜单打开或战局退出后清除显示。
- 与容器详情共用左侧区域，AI 信息可见时暂时让出容器详情区；支持长行换行及 PageUp／PageDown 翻页。读取不改变 Buff 编辑器的目标、手动效果记录或角色状态。
- “传送与导航 → 角色传送 → 其他玩家”新增当前战局存活玩家列表。执行时重新检查战局、对象指针、档案 ID 和存活状态，并将本地玩家传送到对方附近可站立的位置。该入口始终传送本地角色。
- 其他玩家使用独立的目标引用，现有 AI 编辑／批量传送的 AI 限制保持不变。

验证：Release 构建、完整 Probe 回归、原生效果／针剂子效果 API 与只读读取边界、目标重新解析与本地传送路径检查。实机准星识别、画面与 Fika 玩家位置同步仍需游戏内确认；客户端只能显示游戏当前同步到本机的效果数据。

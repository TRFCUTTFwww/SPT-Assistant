# 下拉选择、自定义报价与供大于求

基于 `a2f9e4b`，2.4 开发更新，2026-11-26。

## 下拉选择

- 库存右键编辑 → JSON：格式化、复制、粘贴、整树带钩、整树满耐久和刷新归入「JSON 操作」；物品与子组件改为下拉定位，保留名称、插槽、堆叠数和查找功能。
- 剧情：商人和任务状态各使用一个下拉框；每条任务的启用、解锁、完成、重做或剧情走向操作归入「任务操作」。原有修改预览与确认保留。

- 服务端 JSON：「文件操作」管理重载、历史备份和刷新；「节点操作」管理格式化、还原、导入导出及可用的增删操作，保存按钮保持直接可见。
- 下拉列表在滚动区域之外绘制，限制在屏幕范围内；支持滚轮、方向键、Enter、Escape 和点击外部关闭。选择时先处理鼠标事件，避免触发下方控件。

## 自定义跳蚤报价

入口：跳蚤市场的页面下拉框 → 自定义报价。原生跳蚤「跳蚤设置」抽屉共用该入口。

- 按名称或模板 ID 搜索并选择出售物品，设置玩家名、卢布单价、存量、剩余分钟、市场信誉及当前／最大耐久。
- 单价和存量支持 `1～2147483647`，剩余时间支持 `1～43200` 分钟，信誉支持 `0～1000000`。
- 耐久同时留空时使用默认值；填写时必须满足 `0 ≤ 当前耐久 ≤ 最大耐久 ≤ 物品模板上限`。没有耐久组件的物品不接受耐久参数。
- 使用服务端原生报价池，可在游戏原生跳蚤搜索和购买。枪械优先使用默认预设并重新分配组件 ID，保留配件树。
- 支持查看并二次确认移除自定义报价。重新生成 AI 报盘会保留自定义报价。
- 报价只在当前服务端运行期间有效；正常情况下售罄或到期自动移除，重启服务端后不保留。添加报价后刷新原生跳蚤列表即可查看。

## 供大于求

- 「供大于求（商人）」沿用原商人购买无上限配置，旧设置保持兼容。
- 新增独立的「供大于求（市场）」：AI 和自定义跳蚤报价的存量为 `Int32.MaxValue`（`2147483647`），移除个人购买限制，并跳过库存扣减。该开关不覆盖真实玩家报价或原生商人报价。
- 市场库存覆盖作用于临时副本。关闭后恢复报价原本剩余存量及正常购买扣减；价格、耐久和配件保持原值，到期时间仍有效。

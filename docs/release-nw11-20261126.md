# Nw11 夜视与昼视（2026-11-26）

入口：**视觉 → 瞄准镜**，在“全屏夜视效果”或“镜内夜视效果”选择下列预设，再开启对应的夜视开关。两组独立选择，继续使用各自的光源屏蔽开关。

| 效果 | 画面 | 默认暗部增益 | 默认对比度 |
| --- | --- | --- | --- |
| Nw11 绿 | 绿色单色、无夜视噪点、无设备遮罩 | 12 | 1.24 |
| Nw11 蓝 | 蓝色单色、无夜视噪点、无设备遮罩 | 12 | 1.24 |
| Nw11昼 | 保留场景彩色、增强暗部、无夜视噪点 | 10 | 1.08 |

三个预设复用游戏现有的后处理色调通道，替换所选相机的 LUT，不新增全屏渲染通道，不持续读取 GPU 图像。曲线提高暗部可见度并压缩高光，保留纯黑与纯白；昼视按 RGB 比例增强亮度，减少彩色高光被分别裁切造成的偏色。额外环境补光仅在对应相机渲染期间生效；嵌套镜内相机使用同一原始环境光基线，渲染结束、中断、离局和热更新时恢复。

选择 Nw11 时停用对应画面的原生夜视单色处理和后处理颗粒，原生设备效果及此前配置在关闭功能时恢复。“以所选效果开始自定义”会同时复制 Nw11 渲染、颜色保留、暗部增益、对比度和补光设置；可使用任意 HEX 颜色。数值只校验有限性，不增加人工输入范围。六款原生设备预设及此前配置枚举保持兼容。

Nw11昼改变本地相机的可见度，战局时间、天气时间及 AI 逻辑保持原状。夜晚天空、太阳方向、阴影、雾和材质仍来自实际环境，因此它是彩色暗部增强，不等同于把整个世界重建为正午。

验证记录：客户端 Release 构建通过；147 项夜视检查通过，包含原有设备参数、光源屏蔽与恢复，以及新增色调单调性、黑白端点、暗部提升、昼视颜色比例、自定义复制、原配置枚举兼容和全屏／镜内四组环境补光组合。使用正在运行的游戏内置 Hidden/PostProcessing/Uber 着色器完成离屏 GPU 校验，三个预设均通过；当前项目为 Gamma 色彩空间。客户端已热加载 generation 16，ready=true、error=null，部署与运行模块 SHA256 一致。游戏内实际观感与性能仍待用户验证。

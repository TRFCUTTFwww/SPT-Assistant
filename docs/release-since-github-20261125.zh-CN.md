## 新增功能

### 瞄准镜与射击

- **倍镜贴纸编辑器**：开镜后按默认 `Ctrl+F10` 编辑；支持 PNG/JPEG 导入、拖动、缩放、透明度和旋转，按倍镜及图片分别保存布局，并记住最后使用的图片。
- **贴纸切换与效果**：默认 `↑ / ↓` 切换上一张、下一张，支持改键及首尾循环；新增自动黑白高对比度与确认命中闪色，支持 RGB/HEX 和闪烁时长设置。
- **扩展光学倍率**：独立开关位于「视觉 → 瞄准镜」，`Alt+滚轮` 可将倍率扩展至光学相机允许范围，定倍镜同样支持；游戏原生的「调整瞄具分划或倍率」快捷键继续使用镜具原有倍率端点。
- **倍率与灵敏度联动**：原生倍率范围内沿用游戏计算，超出镜具端点后继续按实际光学倍率缩放灵敏度；关闭、收镜或卸载时恢复。
- **开镜不抖动**：新增独立开关，减轻本地玩家瞄准时的呼吸和持枪晃动，与无后座分别控制。
- **子弹穿墙**：新增可选开关，用于本地玩家普通枪弹穿过场景掩体，目标命中与护甲仍由游戏结算。
- **跨口径装填**：弹匣混装与枪膛兼容使用两个独立开关，覆盖仓库、藏身处靶场和本地单人战局，并支持转轮弹巢。

### 人物、物品与存档

- **草丛与沼泽移动**：「人物 → 移动与穿墙」新增「草丛不减速」和「沼泽不减速」两个独立开关；关闭或卸载后恢复原生限制。
- **单项 Buff**：新增原生单项效果选择，可设置持续时间、强度，以及适用效果的作用部位或技能参数，并补全效果名称。
- **自有物品编辑**：仓库和本地战局中的自有物品右键新增「编辑」，可修改该物品支持的耐久、使用余量、钥匙次数、开关及战局内发现标记。
- **狗牌编辑**：支持名字、击杀时间、阵营、等级、状态和击杀武器；移除 10,000 等级上限，客户端、命令和服务端校验保持一致。
- **角色 JSON 编辑器**：「数据 → JSON 编辑」支持树状浏览、搜索、字段用途与实体名称解析、节点修改及整档导入导出，保存前自动备份，并校验身份与库存结构。
- **战局历史补发**：可把历史记录中的入场装备、撤离或保留物品通过游戏系统邮件重新发送。
- **Nw11 联系人**：新增聊天联系人及独立头像，并修复本机聊天身份解密失败后的恢复流程。

### 跳蚤市场与交易

- **独立跳蚤市场页面**：同步 PvP/PvE 基准价格，按单品设置价格与出售权限，支持范围/类别筛选、批量操作，以及命名方案的保存、切换、重命名、删除和 JSON 导入导出。
- **市场规则开关**：新增非任务物品及高级护甲板解禁、等级及分类限制解除、购买物品 FIR、AI 报价满状态且保留插板、卢布市场、隐藏 AI 物物交换报价和实时重建 AI 报价等选项。
- **自动定价与收益对比**：原生上架窗口可按最低价减一、均价或最高价乘倍率自动定价，并比较商人最高回收价与跳蚤税后收益。
- **战局内交易**：「线上交易」允许本地单人战局中右键自有物品并使用原生窗口上架；新增直购到背包，无法放入的部分转入系统邮件。
- **自由贸易与批量售出**：分别取消同时在售挂单数量上限和单笔上架物品数量上限。
- **走私者**：新增独立开关，解除本地单人战局物品带入和非 FIR 物品超限丢弃限制，并保护丢弃容器内的受限物品。

### 战局、画面与场景编辑

- **战局事件通知**：新增 BTR 发车/到站/离站、飞机到来、空投投下、BOSS 死亡、装甲列车到站/发车通知，可分别控制弹出和提醒。
- **选图时钟暂停**：原生早晚时钟旁新增暂停/恢复，开局采用选定时刻；助手倒计时与原生 `O` 键面板统一显示秒数。
- **天空调色板**：「时间与环境」支持天空染色预设、RGB 与 HEX 输入。
- **视野内地点标记**：可把撤离点、BTR 站点、追踪物品和传送标记限制在当前镜头视野内。
- **物品 ESP 配色与弹药详情**：新增类别自定义颜色和按穿透/伤害变化的弹药渐变色；详情增加口径、伤害、穿透、护甲伤害、初速、后坐修正和同口径相邻等级。现金与赛季文件不再计入 ESP 估值。
- **连续容器放置改进**：预览跟随准星，支持浮空、穿模和距离调整，网格吸附默认关闭，地面吸附与碰撞限制分别设置。
- **菜单插画**：新增可选分类背景、切换动画和剧情插画，优化底部对齐与背景比例；保留现有带图标菜单。
- **AI 难度输入**：支持直接输入更精细的非负自定义倍率，不再受原滑块区间限制。

### 内存编辑器与热更新

- **独立内存编辑工作区**：新增内存扫描、地址表、访问监控、反汇编、代码补丁和内存浏览六个页签。
- **扫描与地址表**：支持未知初值、比较/范围、浮点舍入、通配 AOB、UTF-8/UTF-16 字符串、扫描范围与非对齐选项，以及地址锁定、指针链、整表保存和局部热键。
- **硬件访问监控**：支持 x64 硬件断点、读写来源定位、通用寄存器与 XMM0–XMM15 快照、上下文查看及导出。
- **反汇编与代码补丁**：支持按当前进程地址浏览、可配置前后上下文与回退、NOP/运算/分支修改、Intel 汇编、AVX 指令、代码洞注入及持久化 AOB 补丁脚本，卸载时恢复活动补丁。
- **指针反查与结构体剖析**：新增静态指针扫描、字段变化对比、指针钻取和多种十六进制解析/写入方式。
- **本地热更新入口**：可在「设置与热键 → 版本更新」选择核心 `.module` 或 `.dll`，由现有宿主加载；Gitea CI 新增 EFT 48558 构建与带提交号/UTC 时间的模块产物。

## 修复与优化

- 修复跨口径弹药仍被底层过滤拦截、放入弹匣后无法供弹，以及藏身处或新换武器无法上膛的问题；减少拖动弹药时的重复库存扫描和卡顿。
- 修复倍镜贴纸倒置、比例失真和随投影抖动；修复原生瞄具更新覆盖扩展倍率，以及超出倍率端点后灵敏度不再变化的问题。贴纸与变倍设置合并到同一「瞄准镜」页。
- 修复草丛独立 `Swamp_collider` 没有树木组件而漏匹配的问题，改用原生草丛区域计数和减速标记判断。
- 弹夹信息的「膛内 1」改为实弹完整规格，空膛单独显示；转轮读取当前弹巢，排除已击发弹壳，长名称自动换行。
- 无后座挂钩即时检查当前本地持枪控制器，避免沿用旧武器；稳定瞄准的临时参数在单次计算结束后恢复。
- 「无限火箭筒」扩展至本地单人战局内所有已装填实弹的火箭发射器。
- 命中提示改为在射击结算后读取实际扣血，减少伤害误显示为 0；小于 0.1 的正扣血显示为 `<0.1`。
- 战局内直购按原订单重试，避免重复扣费；保存失败回滚，邮件补发等待送达确认。修复物品右键「编辑」按钮在热更新后累积。
- JSON 节点保存只检查被修改节点的冲突，避免无关后台更新阻塞保存；保留档案其他位置的新数据。
- 减少左下角 JavaScript 快照采集、序列化、脚本解析和物品 ESP 标签测量的重复开销。
- 清理失效流血贴花节点和退局玩家引用，阻止结算期间迟到的 AI 生成，修复菜单输入焦点及部分内存编辑按钮重叠。

## 移除

- 移除独立赛季角色、客户端赛季入口及服务端账号路由。
- 移除普通游戏报错触发的自动暂停、蓝屏式恢复界面、紧急救援退局和外部崩溃监控程序；保留热更新本身的失败处理、回退和诊断日志。

# 趣味模块删除与卸载（2026-11-26）

“趣味功能 → 模块管理”中，每个已安装模块的“启用／关闭”旁新增“删除”。首次点击后按钮变为“确认删除”，5 秒内再次点击执行卸载。内置镭射眼继续保留。

卸载请求先移走模块的加载清单，使用现有通用宿主的 CanReload / Shutdown 流程；模块正在执行操作时等待操作结束，确认停止后删除该模块的安装文件及旧版本。等待期间显示“正在卸载”，设置入口隐藏。配置与 state/data 持久化数据保留，再次载入 .module 可以继续使用。此操作不删除服务端物品定义及玩家存档中的物品。

卸载请求写入磁盘，主辅助热更新后继续处理。只接受当前进程、新鲜且晚于卸载请求的宿主确认；仍运行、清理失败或不匹配进程的记录不会触发文件删除。删除前验证模块 ID、绝对目录边界与目录树，拒绝链接。

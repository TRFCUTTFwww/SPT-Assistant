# 狗牌与光学瞄具控制

- 狗牌编辑移除 10,000 等级上限，保留正整数校验；物品编辑、物品命令和服务端保存一致。
- 倍镜贴纸默认按 ↑ 上一张、↓ 下一张，可在倍镜贴纸设置或热键页改键。首尾循环，恢复当前倍镜下每张图片已保存的布局；编辑中切换保持原有保存／取消流程。
- 光学瞄具使用 Alt+滚轮扩展倍率，按相机实际接受范围收敛。原生「调整瞄具分划或倍率」继续切换瞄具自身的端点；切换瞄具、退出开镜及热卸载会释放扩展倍率。

修复：扩展倍率改为更新原生瞄具控制器，由原生光学相机流程应用；定倍镜调用原生瞄具参数应用。开关位于「视觉 → 瞄准镜 → Alt+滚轮扩展倍率」，关闭时恢复原生倍率。

灵敏度：保留瞄具原生范围内的计算，超出端点后按实际光学倍率继续缩放；定倍镜同样生效。关闭、退出开镜或卸载时恢复原生灵敏度。变倍开关与贴纸共用「瞄准镜」页。

验证：EFT 48558 客户端与服务端 Release 构建通过；163 组 Probe、40 项原生倍率流程／灵敏度／开关／端点／定倍镜／卸载检查通过。服务端保存回读验证覆盖狗牌等级 10,001、1,000,000 和 Int32.MaxValue。贴纸回归覆盖双向首尾循环、图片布局隔离、保存失败保留旧方案。

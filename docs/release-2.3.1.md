# SPT Assistant 2.3.1（实验版）

适配 SPT 5.0 BE / EFT 1.3.0.1.48558。继续使用双击 EXE 的离线图形安装方式。

- 人物 → 生存防护：AI 忽略玩家及其热键；人物 → 交互能力：破门强开与独立门卡破解开关。门卡破解需要已安装网络接入仓，安装器会更新其兼容功能模块。
- 人物 → 部位血量：编辑各部位、能量和水分的当前值与最大值；大厅保存到存档，战局中修改本地存活角色并读回。
- 载具 → 装甲列车：立即到站、立即发车、修改距到站/发车的秒数；使用原生列车曲线和撤离流程，已发车的列车不能倒回。
- BTR 按钮明确为“派遣 BTR 至最近站点”；视觉 → BTR 站点可查看原生站点位置和距离。
- 战局 → 时间与环境：行动前保存下次战局时长，单位分钟，0 恢复地图默认；不改变正在进行的战局。
- 杂项：背叛者（原“好”兄弟）、有朋自远方来（仅取消灯塔商人合法访问的时间限制）、趣味物品开关（重启服务端后生效）。关闭趣味物品停止售卖、兑换和能力，保留模板及已有物品以避免丢失。
- 看不见我：增加边界狙击网络事件拦截与原生免疫名单；仍只保护本地玩家免受地图边界狙击，不屏蔽普通 AI 的枪弹。
- 零车费：处理零金额的现金检查、空物品付款和准备付款结果；正金额付款及非货币条件保持原生规则。BTR 也处理免费服务的可支付性检查。
- 时间洪流怀表注册为可放入近战槽手持的物品，仍可随身触发原有能力。已有怀表在服务端重启并重新登录后使用新模板。
- 网络接入仓武器故障：除扣住扳机外，还拦截 AI 射击、枪械出弹与实际射击初始化入口，覆盖走特殊开火路径的 AI；需要进局验证小鹿实际表现。
- 更新代理：提供 HTTP/SOCKS5 地址示例、用户名、遮挡密码输入及清除认证；代理密码只保存在本机配置，配置方案不复制代理账号密码。GitHub 检测兼容本项目实验版 Releases。
- 数据 → 存档备份：[SQLite 完整快照、分类还原、跨角色还原及还原前自动备份](profile-backup.md)。

代码构建、规则检查和隔离服务端验证不代表所有战局表现已验证。列车动画与撤离、边界狙击、小鹿武器故障以及无现金实际乘车/撤离仍须在目标战局验证。

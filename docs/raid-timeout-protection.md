# 超时不迷失

入口：战局 → 时间与环境 → 超时不迷失。

开启后，所设倒计时仍正常归零，显示“超时保护中”，玩家可以继续战局并撤离。原生计时期限在接近到期时获得短暂缓冲，并在继续游玩时续期；O 键面板显示玩家设置的剩余时间。暂停剩余时间同样保护零秒状态。关闭这两个开关后，恢复原先的结束期限，已经超时的战局会重新进入原生超时结算流程。

手动增加时间会退出归零状态；修改时间、恢复计时、切换战局以及卸载模块都会处理各自的计时状态。手动结算、撤离和死亡继续使用原有入口。

EFT 48558 的原生 `GameTimer.GetPastTime` 会把已用时间限制到 `SessionTime`，因此不能用它计算超时后的真实已用时间。当前实现使用原生 `EFT.DateTimeExtensions.UtcNow`、开始时间与停止时间计算经过时长，同时保留结束场景和迷失结算拦截。

离线回归覆盖持续两小时超时、零秒暂停、关闭及重新开启、延长时间、外部修改计时、切换战局与状态清理。编译和热更新检查不代替实际战局到零后继续游玩及正常撤离的验收。

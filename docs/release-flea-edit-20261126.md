# 跳蚤报价编辑（2026-11-26）

## 游戏原生跳蚤

在辅助 MOD 的“跳蚤市场 → 自定义报价”开启“显示修改按钮”（默认关闭）后，选中／展开报价和原生报价右键菜单会显示“修改”。点击打开独立编辑窗口，支持玩家名、出售物品、卢布单价、剩余存量、剩余分钟、市场信誉、当前／最大耐久、SQLite 持久化与暂停剩余时间。修改市场生成报价会创建一条自定义卢布报价并替换原报价。商人和玩家自身报价仍走原生库存／商人管理。保存后手动刷新原生列表。

编辑窗口阻止鼠标穿透及游戏输入；克隆的按钮不继承购买事件。未改变出售物品时保留完整物品树，包含原配件，重新生成物品 ID 和父子关系。编辑失败时保留旧报价及原 SQLite 记录。

## MOD 报价管理

“自定义报价”改为搜索、状态筛选和紧凑列表。每条报价直接提供编辑、删除；持久化报价还可下架、重新上架。删除需要再次点击确认。新增、原生修改和列表编辑共用一个窗口，后台同步不覆盖编辑草稿。

未修改剩余分钟时保持原到期时间。负数仍表示永久；开启“暂停剩余时间”会冻结剩余秒数，报价仍可购买，关闭暂停后从冻结时长继续计时。暂停和永久分别记录。暂停中的报价在原生列表与 MOD 列表显示“已暂停”。如手动改变分钟数，则采用新时长。

SQLite 保存编辑设置、剩余库存、原到期时间、暂停秒数和服务端生成的物品树；重启恢复时不重置有限报价的有效期，也不扣除暂停期间的时间。物品树使用 SPT 原生 JSON 转换器，恢复与重新上架保留非默认配件；旧数据库行没有物品树时继续使用原默认预设路径。未上架的已保存报价在编辑窗口明确显示“保存并重新上架”。

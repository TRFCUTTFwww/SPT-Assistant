# 报价暂停与解除后立即刷新（2026-11-27）

修改报价成功后，服务端生成新报价 ID，但原生列表仍可能持有旧报价行，导致刚保存的暂停或解除状态不能立即显示。

客户端收到保存成功响应后，先应用服务端最新状态，再立即强制重新查询当前打开的原生报价列表。列表随查询返回载入新报价 ID，并使用已更新的暂停状态和冻结时长显示。该流程跳过旧查询缓存，不等待 12 秒定时刷新；新增和其他报价编辑保存也使用同一刷新入口。保存失败不会触发刷新。

本次只修改客户端刷新入口，暂停时长和解除暂停的服务端逻辑不变；界面未添加说明小字。

验证：客户端 Release 构建和本地化检查通过。运行模块哈希与本次构建一致。游戏内列表更新效果由用户检查。

# Nw11 头像与历史战局邮件

- Nw11 聊天头像从原图重新缩放到 256 × 256，供好友列表和对话列表使用。
- 在历史战局详情的「入场装备」或「带出与保留」中选择「重新发送到邮件」，即可将该页签中的装备和物品复制到当前角色的系统邮件。配件、弹药、堆叠和容器内容随物品寄送。口袋内可寄送的物品作为单独附件寄送，任务物品遵循游戏的任务库存规则。
- 邮件附件保留 30 天。同一次发送请求可以重试，也可以手动再次寄送同一份快照。该功能适用于 SQLite 中已经保存且包含相应物品数据的记录。
- 本次更新包含客户端核心、LocalGearMail 服务端宿主和管理模块。更新后需重启 SPT 服务端。

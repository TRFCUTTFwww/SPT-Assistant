# 下架按钮与主仓库新起点（2026-11-26）

## 下架

“跳蚤市场 → 自定义报价”新增“显示下架按钮”，与“显示修改按钮”分别控制、默认关闭。开启后，原生选中／展开报价的操作区和右键菜单显示“下架”。市场生成报价、临时自定义报价及 SQLite 报价均支持；商人和玩家自身报价继续使用游戏原生管理。

下架先保存当前库存、剩余时间、暂停秒数、耐久及完整配件树到 SQLite，再移除原生报价；可在 MOD 自定义报价页重新上架。重复下架不会重复生成保存记录，服务端重启不会自动恢复已下架报价。请求期间禁止重复操作并等待请求结束后热更新；保存后手动刷新游戏跳蚤列表。

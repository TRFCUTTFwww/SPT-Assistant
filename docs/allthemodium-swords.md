目标环境：EFT 48558 / SPT 5.0。每把剑有固定且不同的模板 ID，使用原生近战物品、近战槽、命中判定和存档流程。客户端外观使用 Universal Mod Host 模块，服务端另行注册物品与商人商品。

1.1.3 改用不参与场景雾混色、支持 alpha 的 `Sprites/Default` 材质，避免原先 `Unlit/Texture` 的雾混色使深色区域变白，并加入外观设置。没有修改摄像机伽马、曝光或全局后处理。原始 PNG 不变；调整总是从原始像素计算，只在设置变化时上传纹理，不会反复累乘或每帧重建。

1.1.4 修正 1.1.3 的材质选择：`Sprites/Default` 固定关闭深度写入与背面剔除，立体像素网格的背面、内部面会叠到正面，格挡横举时可能表现为碎边、下半部分错位。改用 `Hidden/Internal-Colored`，将每个像素面的原始颜色映射到顶点；在线性色彩空间中显式执行 sRGB 到线性转换，避免顶点颜色被提亮。100% 不透明时使用不透明队列、深度写入、背面剔除；低于 100% 时使用 alpha 混合并保留背面剔除。保留用户当前亮度、不透明度和尺寸设置。格挡姿势与攻击逻辑未改动；半透明网格仍有常见的表面叠加限制。

1.1.4 验证：模块零警告构建、38 项规则检查、`scripts/Test-PixelSwordSurfaces.py` 七把模型检查通过。新增检查逐面验证 UV 对应原图像素、颜色恒定、源像素不透明及外向绕序，避免改用顶点颜色或背面剔除后丢面。热加载 generation 3 就绪，运行读回全部模型颜色数等于顶点数、ZWrite=1、Cull=Back、队列 2000；用户当前亮度约 49.63%、不透明度 100% 得到保留。实际格挡画面由用户检查。

辅助核心同步修复原生武器回收时缺失雨水组件导致的空引用：忽略空集合与失效条目，保留有效组件的原生启停。已销毁的手部控制器不再进入视觉更新。诊断命令 `hands-state` 查看手部控制器与瞄具骨骼，`hands-guard-check` 检查空雨水集合/条目；`hands-recover` 对已销毁、停在 Remove、预制体和 CCV 均缺失、无排队任务的控制器，通过原生工厂重新拔出同一库存武器，不创建或删除物品。正常控制器仅请求完成当前原生操作，不执行重建。

## 右键格挡（客户端 1.1.1）

四把像素剑在本地玩家手持时，右键改为按住格挡、松开解除，替代原本的刺击；左键继续使用原生挥砍，按左键会中断格挡。待机时剑身在约 0.14 秒内平滑转至屏幕左上方斜举姿势，松开后恢复。方向按摄像机的右/上轴计算，再转换到剑身父级坐标，避免局部旋转轴与屏幕方向不一致。姿势只改变当前持握实例的剑身显示网格，保留游戏的手臂、摄像机、原生碰撞和挥砍动画；不是移植 MC 骨骼动画。原版近战武器及 AI 的右键行为保持原生逻辑。

按住右键、存活且待机时，正面半球的子弹、近战命中造成的生命伤害默认降低 50%（可调 0–100%），在原生护甲处理后缩放实际生命伤害参数。侧后方命中、爆炸、流血、跌落等保持原有伤害，损毁肢体向其他部位传递的伤害不会重复减伤。打开背包、界面占用鼠标、失去焦点、暂停、挥砍、切换武器或死亡时不提供格挡。模块停用或热更新会恢复姿势。该实现以本地玩家为目标，没有验证 Fika 联机同步。

设置入口：**右 Shift → 趣味功能 → 像素剑**，提供启用右键格挡、格挡子弹、格挡减伤（0–100%）和剑模型大小（20–100%）。关闭格挡后恢复原生右键刺击；关闭“格挡子弹”后仅减免近战伤害。默认开启格挡和格挡子弹，减伤 50%，大小 55%。修改立即生效并保存至 `BepInEx/config/local.allthemodium.swords.cfg`；设置由独立剑模块持有，辅助 MOD 通过可选接口显示，支持模块热更新。

## 安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Install-AllTheModiumSwords.ps1
```

初次安装后重启服务端和客户端，客户端登录时才会取得新增模板。随后外观逻辑的更新可用 `scripts/Publish-HotModule.ps1` 发布；服务端物品定义更新需重启服务端并重新登录客户端。

服务端目录：`SPT_Runtime/user/mods/AllTheModiumSwords`。客户端模块：`BepInEx/plugins/UniversalModHost/modules/atm-swords`。模块诊断：`state/atm-swords/status.json`。服务端注册成功会生成 `registration-status.json`，包含当前 PID、时间、四把剑的伤害及原版模板未变化的校验结果。

新剑在耶格（`5c0647fdd443bc2504c2d371`）一级购买。1.0.0 错用了医疗商的 ID，旧文档所说的耶格检查有误；1.0.1 已修正，商人商品变更要重启服务端后生效。辅助 MOD 的物品目录现在异步读取运行中服务端的物品和中英文本地化，刷新前及请求失败时继续使用本机原版目录，因此安装模组新增的物品也能被搜索。第一次进入商店时，游戏若沿用了原版 gladius 的旧图标缓存，可清除客户端图标缓存后重新加载。

游戏内检查由用户完成：四把剑分别购买、装备、拔出、左右键攻击、收起、丢出拾取、仓库与检视显示；切回原版 gladius 后模型应恢复。分别测试无甲与有甲目标。编译和服务端数据检查不代表这些画面与命中效果已实际验证。

离线素材检查可执行 `python scripts/Test-AllTheModiumAssets.py`，覆盖原图 SHA-256、尺寸、UV/索引、封闭面、非退化三角形和映射后的坐标范围。客户端、服务端均针对本机依赖编译。新增物品使用 `OnLoadOrder.Preload`，在存档载入前注册。

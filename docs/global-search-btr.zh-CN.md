# 全局搜索与 BTR 下一站修复

主菜单内容区顶部增加全局搜索，覆盖客户端配置名称、原始键名、分类、说明和页面入口。支持中文、英文以及空格分隔的多个关键词；设置结果可直接修改，页面结果点击进入。另有 Scav 装备直达入口，并为仓库、杂项规则、制作、信誉等常用词补充入口。清空搜索回到当前页面，原有页面搜索保留。

搜索索引和匹配结果缓存；滚动列表只绘制可见结果。搜索不读取存档或发送服务端请求，服务端功能通过对应页面入口进入原有编辑流程。

BTR 原先将原始站点 ID 传给乘客叫车接口；该接口按 `/` 拆分服务 ID 并读取第二段，导致数组越界。现在使用车辆的单参数路线接口，先检查道路连接，再规划相连站点。停站时设置下一段；行驶中完成当前段后，在车辆原生到站流程结束后继续执行。保留停站倒计时，可使用“立即发车”。车辆未驶入地图、站点失效或无可用道路时显示明确提示。关闭 BTR 或切换战局会清空待执行路线。

BTR 页滚动内容高度也已修正，底部提交按钮和提示可完整滚动查看。

验证：115 组 Probe 检查通过；EFT 48558、47888 客户端编译通过，仅保留两条原有 nullable 警告。新增多关键词匹配、中文子串、路线循环、不可达站点、车辆接口选择及到站后续路线挂接检查。界面视觉、实际 BTR 行车效果由用户在游戏内验收。

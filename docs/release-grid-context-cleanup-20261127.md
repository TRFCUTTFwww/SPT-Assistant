# 2.4 — 空格右键菜单清理（2026-11-27）

- 修复先右键物品、再右键空格时，前一物品的“编辑”、FIR 和“新增报价”按钮残留到空格菜单的问题。
- 物品和空格复用同一个游戏原生菜单。物品操作按钮由助手直接加入按钮池，不属于原生动态菜单的清理生命周期；空格菜单显示前现显式复用物品菜单的清理逻辑，释放对应按钮池实例及旧回调。
- 空格菜单仅保留目录添加、JSON 添加和剪贴板 JSON 添加三个入口；重新右键物品时仍按当前物品及对应开关生成物品操作。
- 验证：客户端 Release 编译与差异检查；实际菜单切换显示由用户在游戏内复查。

复查顺序：右键物品 A → 右键空格 → 右键物品 B → 右键空格；空格菜单不应出现编辑、FIR 或新增报价，物品 B 的操作应针对 B。

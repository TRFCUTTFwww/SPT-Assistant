游戏时间暂停
- 入口：右 Shift → 战局 → 时间与环境 → 时间控制 → 暂停游戏时间；右侧昼夜与天气中也可操作同一开关。
- 暂停固定游戏中的昼夜时刻。战局剩余倒计时由旁边的“暂停剩余时间”独立控制；需要两者一起暂停时，分别开启。
- 原生 GameDateTime.Lock 只设置锁定标志，Calculate 不检查该标志。现在用零时间流速实际停止昼夜推进，并保留原生锁定状态。
- 暂停优先于系统时钟同步和自定义流速。同步选项保留，暂停期间暂缓对时，恢复后重新对齐电脑本地时间。
- 切换流速、暂停、恢复及卸载模块时，以当前游戏时刻重新建立计时基点，避免把已过去的时间按新倍数重算。退出战局及卸载时恢复接管前的流速、修正倍数与锁定状态。
- 时间卡片和悬浮窗会显示游戏时间已暂停。沿用旧 Freeze time 配置，不重置已有偏好；补齐英文说明和状态翻译。

倒计时清晰度
- 时间菜单卡片与常驻时间悬浮窗的剩余时间，低于十分钟时改用较亮的警示红。
- 剩余时间文字添加一物理像素的黑色细描边，绘制位置与行高对齐像素，改善调整窗口大小后小字号文字的清晰度。
- 文字及描边独立于悬浮窗底板不透明度，降低底板不透明度时仍可读。
- 保留原有绿／黄／红阈值：超过本局总时长一半为绿色，低于十分钟为红色，其余为黄色。

验证
- 48558 与 47888 客户端分别构建通过，均为零错误及两条原有空引用警告。
- Probe 全部检查通过，覆盖倒计时阈值、剩余时间暂停、时间编辑、悬浮窗尺寸边界与中英文目录。
- 离线检查 48558 原生 Calculate、Lock、Unlock、ResetForce：确认锁定标志不参与时钟计算，计算使用两个流速因子；ResetForce 保留流速并重建时间基点。
- 游戏内视觉和交互仍由用户验收：暂停后等待十秒，游戏时刻应不变；关闭暂停应继续推进，系统同步开启时应恢复系统时刻。分别检查剩余时间暂停、低于十分钟的红字、缩放后的窗口和透明底板。

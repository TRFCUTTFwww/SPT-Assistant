# 杂项规则与 Scav 装备编辑

侧栏新增「杂项」，每项规则独立开关、默认关闭：

- **“好”兄弟**：Scav 出战中，原生 Scav/BOSS 击杀来源的 Fence 扣分改为等额加分。
- **关系户**：Scav 可选择实验室、迷宫和破冰船，保留其他原生入场条件。
- **人情世故**：投保费用为零。
- **客户就是上帝**：所有地图已投保的遗失装备回保率为 100%。
- **我没看到**：边界狙击区不射击本地玩家。
- **违禁品**：Scav 独立安全箱，默认 Alpha，可从当前数据库提供的原生箱型中选择。一键售卖、撤离、阵亡和 Scav 重生成保留箱及内容；与 PMC 库存分开。有内容时禁止更换箱型。关闭开关保留已存内容。
- **诚信经营**：跳蚤市场挂单手续费为零。
- **加急件**：新保险回送不再等待，下一次保险检查发信，保留领取期限。

地图与安全箱显示变更后重新登录角色；费用变更后重新打开报价页面。所有配置修改要求退出战局，保存前备份角色和设置；拒绝过期版本的修改。

「数据 → 角色管理 → Scav 装备」新增近战武器槽。弹挂、背包卡片下方可「编辑内容物」：搜索添加、修改单组数量、删除条目；返回方案后统一「保存并应用」。可选择仅下一次或以后每次 Scav 出击。

原有内容物保留属性、配件与内嵌物品。更换容器会清空该槽的内容物草稿；数量不得超过物品堆叠上限。服务端按原生物品尺寸、旋转、多个储物格和过滤器摆放；放不下或来源已变化时拒绝整个方案。应用装备只替换可编辑槽位，保留独立安全箱。

本次更新包含 `LocalGearMail.dll` 固定接口变更，安装后须重启服务端一次；之后重新登录角色并刷新装备页。管理模块和客户端模块可热加载。

验证：48558、47888 客户端编译通过；110 组 Probe、22 组服务端检查通过。新增用例覆盖近战、弹挂/背包内容、原生格位边界和重叠、序列化后属性保留、无效/超堆叠/超容量拒绝、跨容器修改原子性、安全箱售卖排除及非空箱型更换保护。原存档仅作只读副本检查。实际游戏内视觉和出击结算由用户验收。

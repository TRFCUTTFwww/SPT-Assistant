# SPT Assistant 2.4
[English](release-2.4.md)

适用 SPT 5.0 BE / EFT 1.3.0.1.48558，Windows x64。以下为相对 GitHub v2.3.5 的更新。

## 下载文件

- `SPT-Assistant-2.4-Setup.exe`：完整离线安装程序。全程同时显示中英双语，语言选择器设置游戏内辅助语言。
- `Local.Spt5.ESP.Core.module`：供已有安装单独更新核心。在「设置与热键 → 版本更新」选择加载，或关闭游戏后替换已安装核心；服务端组件和外部资源更新需使用完整安装包。
- `SPT-Assistant-2.4-experimental.zip`：手动安装包。
- `SHA256SUMS.txt`：上述三个文件的 SHA-256 校验值。

## 新增与改进

- 优化单页安装器，标签、模式、进度、错误及恢复操作同时显示双语，小窗口支持滚动。安装标题、EXE 元数据和应用清单统一使用发布版本号。
- 新增倍镜贴纸导入与编辑、按镜具保存布局、上下键切换、自动对比度和命中闪色。
- 新增可选原生扩展光学倍率，使用 Alt+滚轮，支持定倍镜及灵敏度联动；原生分划／倍率快捷键保持镜具原有端点。
- 新增开镜不抖动、可选子弹穿墙，以及独立的弹匣混装和枪膛跨口径兼容；修复供弹与上膛，扩大无限火箭筒适用范围。
- 新增独立的草丛不减速、沼泽不减速开关，修复草丛碰撞体漏识别。弹夹信息显示膛内实弹规格，支持转轮及空膛状态。
- 新增自有物品与狗牌编辑，移除狗牌 10,000 等级上限；新增单项 Buff、角色 JSON 编辑与备份、战局历史补发及 Nw11 聊天联系人。
- 新增独立跳蚤市场页面、PvP/PvE 价格、单品价格与权限、命名方案、规则开关、自动定价及税后收益比较。
- 新增战局内上架、背包直购与溢出邮件、独立挂单限制及走私者限制开关；修复购买重试和保存失败回滚。
- 新增战局事件通知、选图时钟暂停、天空 RGB/HEX 调色、视野内标记筛选、物品配色和弹药属性详情。
- 改进连续容器放置、可选菜单插画和 AI 难度精确输入。
- 新增六页内存编辑器，支持扫描、地址锁定、硬件访问监控、寄存器快照、反汇编／汇编、代码洞、AOB 补丁、指针扫描及结构体剖析。
- 新增本地模块选择及 Gitea CI 产物；减少库存扫描、JavaScript 快照和 ESP 重复开销，修复伤害提示、热更新重复菜单、输入焦点和退局清理。

- 修复重复安装时资源备份和回滚受 Windows 传统路径长度限制而失败的问题。
- 吉祥物背景改为默认关闭。

- 自定义跳蚤报价支持 SQLite 持久化、修改、下架和暂停剩余时间，统一工具栏及报价排版。
- 新增独立夜视页面，提供全屏和镜内 Nw11 绿、蓝、Nw11昼；瞄准镜页面改名为“瞄准镜贴纸”。
- 模块支持保留数据的卸载及重新导入。地图模式移至末尾，服务端页面加入用户提供的背景图。

## 移除

- 内置倍镜贴纸图片；保留导入、编辑及切换功能，空图片库不绘制贴纸。

- 独立赛季角色及入口。
- 普通游戏报错自动暂停、全屏恢复界面、紧急救援退局及外部崩溃监控；保留热更新失败处理、回退和诊断日志。

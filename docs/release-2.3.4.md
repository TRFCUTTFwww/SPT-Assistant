# SPT Assistant 2.3.4

适用 SPT 5.0 BE / EFT 48558，继续使用宿主 1.6.2。

- 修正角色／模式选择里的“赛季”槽位仍显示未解锁的问题。SPT 的原生返回将 pvp-season 固定为 locked；此前的补丁只开放主菜单赛季内容入口，未处理这个槽位。
- 开启“数据 → 赛季 → PVE 开放赛季入口”后，锁定的赛季卡片显示当前 PVE 角色，按钮为“选择 PVE 赛季”。卡片注明装备、任务和进度共用。提交时校验当前控制器和角色身份，并将模式参数明确转为 Pve；不创建新角色、不重置进度、不修改服务端锁定数据。
- 没有现成可选 PVE 角色、处于战局、开关关闭或角色不匹配时，不提供这个入口。原本已支持且未锁定的原生赛季角色保留原来的选择流程。关闭开关和卸载模块会恢复原生锁定卡片。
- “设置与热键 → 主题与布局”新增左下角版本文字开关、输入框、应用与恢复原始按钮；“镜头与画面 → 界面布局”也可访问。默认保留原始文字，最多 160 个字符，按普通文字显示；留空、关闭或卸载恢复原始显示。只修改角落标签，不改变真实版本、服务器协议或兼容性判断。

赛季入口使用现有 PVE 存档，不是独立的赛季角色。SPT 未实现的在线联赛与奖励接口仍以本机原生支持为准。

构建、选择身份保护及回归检查见 validation-2.3.4.json；游戏内视觉与实际选择由用户检查。

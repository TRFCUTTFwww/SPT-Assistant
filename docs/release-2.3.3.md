# SPT Assistant 2.3.3

适用 SPT 5.0 BE / EFT 48558，宿主 1.6.2。

- 补齐诊断、调试、右键菜单、血量、列车、备份、趣味物品、BTR 与更新提示的英文；保留物品、角色和站点名称，支持动态计数与状态句。
- 错误保护界面改为固定操作区与可滚动正文，技术信息可展开和复制，适应窄屏。区分备份成功、结算等待、结算超时和已退出战局；备份回执不再覆盖失败提示。独立崩溃提示和热更新进度也支持英文。
- 数据 → 仪式圈：奖励预览默认开启，仅在页面打开时查询；献祭开始后读取本次已生成奖励，不重抽、不移动物品、不提前领取。
- 仪式圈提供“立即完成本次仪式”和默认关闭的“自动秒完成”。材料照常消耗，奖励手动领取。服务端使用原生仪式完成标记，操作前备份；校验角色、配方、开工时间与奖励身份，拒绝过期请求。普通制作、情报中心和连续生产不受影响。
- 数据 → 赛季：默认允许在 PVE 菜单展示原生 Seasons 入口，也提供直接打开按钮。仅在本机原生控制器和赛季数据就绪时开放；不切换角色模式、不重置角色、不修改奖励解锁条件。SPT 未实现的在线联赛或赛季接口不在此补丁中模拟，具体可用内容依赖本机服务端。

客户端功能模块与服务端管理模块可热更新。宿主和独立崩溃提示的更新在下次启动相应进程后生效；运行中的旧宿主通过兼容桥使用新版错误界面。

验证见 validation-2.3.3.json。

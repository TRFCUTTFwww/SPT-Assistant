# 错误保护与测试边界

空引用、数组越界和模块加载失败都可能在真实游戏或 Mod 运行中出现。例如对象已销毁却继续访问、列表刷新后使用旧索引、热更模块依赖或初始化失败。它们属于值得测试的错误处理场景；目前没有证据表明用户的游戏已实际发生这些故障。

栈溢出和非法内存访问同样可能发生，但真实线程栈耗尽或原生指针错误通常会直接终止进程。手动抛出同名托管异常，不能证明能够捕获并恢复真实原生崩溃，也不能保证完成物品备份。

调试页将空引用/越界的受控托管异常、热更新失败演练、原生致命错误的报告界面演练分开解释。栈溢出与内存错误按钮只提交报告，不执行危险操作。真实错误与模拟均保留明确标识；模拟不触发背包救援或战局结算。

保护界面移除大表情，压缩标题区；宽窗口并列显示原因与物品保护状态，窄窗口改为纵向，长内容独立滚动。技术堆栈默认折叠，操作区固定。备份成功与服务端结算完成仍分开显示，未确认时不会宣称物品已安全结算。

宿主回归覆盖模拟结束返回、失败初始化、损坏候选、手动回退、卸载失败保护、时间/鼠标恢复与八种窗口尺寸的布局边界；游戏内视觉效果由用户核对。

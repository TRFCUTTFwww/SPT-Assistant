# 辅助 Mod 2.2：内置黑墙脉冲

黑墙动作、特效、声音和伤害逻辑已直接编译进辅助核心，来源为用户已确认各视角可见的独立版 0.2.10。入口：模型与镜头 → 趣味功能 → 黑墙脉冲；F11 施放、Alt+F11 无伤静音预览，支持改键。全屏滤镜可单独关闭，AI 无敌保护仍优先。

发布包包含 `payload/Blackwall/Assets` 下的动作、PNG 贴图和 WAV 音频，完整清单及 SHA256 见 `blackwall-assets.json`。安装至 `BepInEx/plugins/LocalSpt5ESP/Blackwall/Assets`，不依赖独立 DLL。源码不内嵌二进制资源；从源码打包时用 `Build-ExperimentalRelease.ps1 -BlackwallAssetRoot <资源目录>`，只收录清单内文件。

安装器先验证、复制所有资源和辅助模块，再将原 `BepInEx/plugins/BlackwallPulse` 整个目录移至 `mod-backups/assistant-2.2-*/disabled-standalone-BlackwallPulse`，避免 BepInEx 递归发现独立 DLL。安装失败回滚。旧独立配置保留在 BepInEx/config，辅助继续使用原来的“65. 黑墙脉冲”设置。运行时也会停止已加载的旧独立黑墙，避免重复施法、音效和相机回调。

黑墙随辅助核心统一热更新及卸载；取消或卸载恢复原手臂、销毁临时网格并移除相机回调。空放和无伤动作预览静音，声音仅在确认击杀后播放，独立音效试听可用。2.2 合并后的实际战局效果仍需验收。

## 本机安装

关闭游戏客户端，从源码根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-BlackwallPulse.ps1 -GameRoot 'D:\SPT-5.0.0-48558' -ResourceRoot 'D:\CP2077_Blackwall_Supplement_20261112' -Dotnet 'D:\SPT_Mod_Staging_20261027\dotnet-sdk\dotnet.exe'
```

安装器先核对所用资源的 SHA-256，构建黑墙客户端模块并备份旧文件。安装动画、纹理及本地导出的声音素材。资源取自用户本地导出，不进入源码仓库或公共发布包。首次安装需要启动客户端；已有承载插件的后续更新可加 `-HotUpdate`，更新能力热模块；辅助桥接由辅助项目单独安装。若启动 DLL 被占用，当前客户端通过既有承载组件运行新热模块；独立启动文件可在关闭客户端后更新。

独立插件配置在 `BepInEx/config/local.blackwall.pulse.cfg`。辅助 Mod 连接期间以辅助页面设置为准；辅助 Mod 缺席时读取独立配置，可设置 `Standalone key` 使用。插件不依赖辅助 Mod 启动。诊断写入 `BepInEx/plugins/BlackwallPulse/blackwall-state.json`，辅助诊断动作名为 `blackwall-state`。

## 验证边界

离线检查覆盖目标排除、穿墙开关、一次施放只释放一次、中断取消、无额外冷却、动作混合、实际 GLB 解码、手指运动与完整时长。编译和离线检查不能证明手臂适配、身体纹理、声音时机已在游戏内正确显示。

进战局后先按 Alt+F11 检查抬手、握拳、收手及武器恢复；再对少量 AI 按 F11 检查侵蚀、死亡与搜刮。游戏内界面和画面由用户检查。当前不包含 FIKA 同步。

卸载独立能力时移走 `BepInEx/plugins/BlackwallPulse` 文件夹；辅助 Mod 会显示未连接，不影响其余功能。

# 2026-11-26 综合功能增强说明 / Feature Enhancements

2026-11-26，2.4 开发更新。

## 1. 瞄准镜、测距联动与贴纸方案管理
- **测距窗信息扩展**：支持同框显示实时实际倍率（含 `Alt+滚轮` 扩展倍率）与当前瞄具归零档位（如 `186.4 m · 9.5× · Z200`）；射线指中存活角色时高亮变色。
- **机瞄与一倍镜测距**：新增可选开关，开启后使用红点、全息或机瞄开镜时回退主相机中心射线测距。
- **一键／自动归零**：支持快捷键（默认 `Alt+Z`）或开镜持续自动将当前瞄具归零切换到最接近测距距离的档位。
- **位置拖拽与贴纸库管理**：`Ctrl+F10` 倍镜贴纸编辑模式下可直接拖拽测距窗位置；设置页新增重置测距窗位置、清理未引用贴纸图片，以及对已保存倍镜方案执行“设为默认”或“删除”。

## 2. 右键编辑：枪械数值页签与物品树 JSON 导航
- **右键「枪械数值」页签**：右键任意枪械点击“编辑”时，新增与开发工具“枪械编辑”对标的数值页签，支持战局内外修改单把枪实例或同型号模板、忽略配件数值影响、筛选与批量勾选字段，并与 `weapon-tuning-presets.json` 参数方案互通读写。
- **右键「JSON」页签增强**：新增物品树子组件横向点击定位栏（自动解析 `_tpl` 物品名、`slotId` 与堆叠数，点击直接滚动跳转对应 `_id` 块）、页内关键字查找、复制／粘贴 JSON 草稿，以及“整树带钩”和“整树满耐久”快捷草稿修改。

## 3. 游戏内枪械预设管理（导出／导入／删除）
- 在 **物品与装备 → 玩家枪械预设** 与 **枪械编辑 → 游戏枪械预设** 中管理游戏改枪台保存的原生预设（`WeaponBuildsStorage`）：
  - **导出**：支持单套或全部导出为 `.json` 文件，或一键复制 JSON／Base64 到剪贴板。
  - **导入**：支持选择文件、从剪贴板一键导入或粘贴 JSON／Base64 文本（兼容单套预设、预设数组或扁平物品数组），自动校验模板并重新分配全套 `MongoID`，保存后同步写入客户端改枪台与服务端角色配置。
  - **删除**：提供二次确认删除，实时同步客户端与服务端。

## 4. 服务端 JSON 编辑器增强
- **历史备份还原**：工具栏新增“历史备份”抽屉，按时间倒序展示当前文件的备份记录与字节大小，支持二次确认原子还原（还原前自动备份被替换文件）。
- **最近文件与差异提示**：自动记录最近打开／修改的文件并置顶标注 `★`，支持“最近”一键筛选；编辑区底部在保存前实时显示草稿行数、字符增减与首处差异行号。

## 5. 剧情与任务页面：免重登实时生效、商人分类、忽略前置启用
- **免重新登录实时生效**：所有剧情与商人任务修改保存后，自动同步更新客户端 `Profile.QuestsData`、拉取最新任务模板（`RequestQuestsTemplates`）并触发 `Quest` 状态刷新，无需退回选人或重启客户端。
- **按商人分类与状态筛选**：新增商人标签栏（显示各商人名称与任务数）及任务状态分组栏，支持按商人名、任务名或 ID 搜索。
- **忽略前置启用任务**：新增“忽略前置启用”（直接设为进行中并自动激活所属主线章节）与“忽略前置可接”（直接设为可接取），不重置其他无关任务。

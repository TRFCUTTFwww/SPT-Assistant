# 物品透视与 JavaScript 性能

- 归档当前开发构建 20261125-084012.6524897Z：射击后座与镜头后座挂钩均即时检查当前本地持枪控制器，不再保留旧武器标识。稳定瞄准只在单次 ProcessEffectors 计算期间暂时降低呼吸和持枪晃动输入，由 finalizer 恢复。recoil-state 提供当前持枪控制器、临时参数计算与收尾次数及错误计数的只读诊断。构建对应关系和验证见 [当前开发版记录](release-dev-20261125.md)。

- 在仓库或本地战局背包里右键点击自有物品，选择「编辑」可修改该物品支持的耐久、使用余量、钥匙次数、开关和战局内发现标记。仓库修改保存到当前角色档案，本地战局修改随正常结算保存。
- 右键狗牌选择「编辑」，可勾选修改名字、击杀时间、阵营、等级、状态和击杀武器。时间使用 UTC，支持带时区的 ISO 8601 输入。阵营可填 USEC 或 BEAR，击杀武器可填名称或游戏本地化键。

- 战局已经开始退局结算时，救援仍会保存装备快照，随后等待原生退出，避免再次调用退局。

- 左下角 JavaScript 从原生撤离点的列车条件读取列车，快照采集时省去全场景搜索。普通脚本在后台序列化游戏快照，Jint 复用已解析的代码，每次运行仍有独立的脚本状态。性能日志新增 `CornerSnapshot` 和 `CornerLiveScript`，便于查看游戏线程上快照和实时脚本各自的开销。
- 在「视觉 → 物品显示」用 `#RRGGBB` 自定义物品类别颜色。食物和饮料默认蓝色，医疗用品和现金使用绿色系，配件、钥匙和赛季文件使用紫色系。子弹按伤害和穿透从琥珀色渐变至红色，穿透占 60%，伤害占 40%，两个颜色都可修改。橙色用于含高价物品的容器和尸体标题。
- 地面、容器与尸体的 ESP 仍显示现金和赛季文件的名称与数量。这些物品从 ESP 的单项估值及容器和尸体的合计中排除。
- 准星指向地面弹药或弹药包时，左侧物品详情显示口径、伤害、穿透、护甲伤害、初速和后坐修正。容器里的弹种可用 PageUp／PageDown 翻到对应页。相邻等级按同口径穿透力、再按单弹丸伤害排序，同分共用一个等级。弹药包用内容物中强度最高的弹药颜色，空包使用基础弹药色。

## 倍镜贴纸

- 编辑面板新增「自动高对比度」与「命中闪色」，默认均关闭，按“倍镜 + 图片”独立保存。高对比度按贴纸每处背后的镜内亮度显示黑或白，忽略原图 RGB、保留原图 Alpha；命中闪色在确认本地玩家命中角色（含护甲承受的枪弹命中）时优先显示所选颜色，结束后恢复高对比度或原图。其他命中显示、音效关闭时仍可单独使用。
- 命中颜色支持 RGB 三通道整数（0–255）和六位 HEX（可带 #），点击「应用」同步两种输入及色块，再保存方案。无效输入保留已选颜色。闪烁时长可调 50–1000 ms，默认 180 ms，可点击「预览命中闪烁」。切换图片、倍镜或收镜会清除旧闪烁。
- 颜色效果使用原图透明度作为形状：JPG 或完全不透明的 PNG 会呈现整块矩形，建议使用有透明背景的 PNG。无需嵌入 ICC；需要保留原色的图片建议先转换到 sRGB，Unity 不保证读取内嵌 ICC。编辑器无法定位镜片时的单独预览区仍显示原图，颜色效果以实际镜内为准。
- 高对比度复用游戏现有灰度、颜色曲线和 UI 细节材质，在 GPU 上采样镜内背景；遮罩只在图片变更/首次启用效果时准备，普通帧不读取场景像素到 CPU。收镜释放背景纹理，热卸载释放全部效果资源。

- 修复上一版贴纸上下倒置：移除绘制时额外的渲染纹理 Y 翻转，0° 按原图正向显示，保留图像效果后的固定绘制。
- 编辑面板新增「旋转角度」滑块（−180°～180°，正值顺时针），以及「旋转 −90°」「角度归零」「旋转 +90°」按钮。图片绕自身中心旋转，在非正方形倍镜纹理上保持原比例；边框、缩放手柄与预览同步旋转。角度按“倍镜 + 图片”独立保存，旧方案缺少角度时默认 0°，保留原位置、大小、透明度与图片选择。
- 「视觉 → 倍镜贴纸」有独立开关，默认关闭。藏身处靶场和战局均可使用；开镜后按默认快捷键 **Ctrl+F10** 进入编辑，可在该页或热键页修改按键。保存编辑会开启贴纸，取消编辑保留此前开关状态。
- 编辑时在镜片区域左键拖动调整位置，滚轮围绕鼠标缩放，或拖动右上角方块改变大小；面板滑块可精调宽度、水平/垂直位置和透明度。Enter、编辑快捷键或「保存并退出」保存，Esc 或「取消」放弃本次编辑。切换倍镜、收镜、打开主菜单或热卸载时取消未保存的编辑。
- 按倍镜型号及其光学子瞄具分别保存，切换倍率沿用同一方案；同型号不同实物共用方案。**同一倍镜的不同图片也分别保存布局**，换回该图可恢复先前保存的位置、大小和透明度。每只倍镜记住最后保存使用的图片，保存时只更新当前倍镜与图片，不覆盖其他倍镜或其他图片。
- 点击图片名称可切换内置/已导入图片，「导入图片」打开 Windows 文件窗口。支持 PNG、JPG/JPEG，最大 4096 × 4096、16 MB；保留原图颜色和透明度，复制到 `BepInEx/plugins/LocalSpt5ESP/scope-stickers/images`，原文件之后可移动。方案写入同目录下的 `profiles.json`，原子保存失败时保留旧文件和编辑草稿；损坏的方案文件会保留并停止保存，避免覆盖。
- 使用完整透明 PNG，保留右侧手指、头发与衣服，按原始像素处理以避免 DPI 缩放导致裁切。图片原有宽高比在不同倍镜纹理尺寸下保持一致。
- 默认宽度为镜片的 32%，水平位置 8%、垂直位置 0%，透明度 70%。位置从镜片左下角计算，可调整大小、位置与透明度。
- 在光学相机图像效果完成后，用固定正交矩阵向倍镜纹理绘制透明四边形，消除旧实现经过场景投影和时间采样矩阵带来的贴纸偏移。原生镜片负责圆形边缘与眼距裁切。编辑辅助框使用镜片包围盒的屏幕投影估算范围，无法获取范围时提供单独预览区；辅助框不参与实际贴纸绘制。
- 编辑模式拦截原生鼠标、移动和开火输入，打开时释放扳机；保存/取消后等待鼠标按钮松开再恢复输入，避免保存点击同时开火。热更新前先释放编辑模式的鼠标占用。
- 贴纸独立于人物 ESP；收镜、切换瞄具、关闭选项或热卸载时移除对应绘制，卸载释放纹理、网格、材质和相机回调。
- 验证：本次 EFT 48558 Release 构建通过（0 错误、3 条既有警告），160 组 Probe 检查通过，包含 RGB/HEX、闪烁时间边界、旧方案默认值、不同倍镜/图片的颜色与效果保存隔离、命中采集独立开关、资源释放和正式构建不含场景读回代码。可选离屏 Unity GPU 检查通过 29 个采样点，验证不对称明暗背景对应、任意原图 RGB、单次透明度、透明及半透明遮罩、镜片 Alpha 保留、指定命中颜色与结束恢复；该检查只在专用验证构建运行，正式模块已排除。923 × 1175 RGBA 素材保持不变；正式模块已热更新至 generation 16，哈希匹配、ready=true，无回滚，新日志无助手相关错误。

## 跳蚤市场

- 助手页使用完整内容宽度。宽窗口把物品操作放到列表右侧，价格源、同步状态和原生入口放在同一行。窄浮窗继续上下排列，空间不足时可滚动物品操作。

- 助手菜单左侧「服务端」下面的「跳蚤市场」支持同步 PvP／PvE 基准价、单品改价和设置出售权限。
- 「显示原生跳蚤按钮」默认关闭。开启后，游戏跳蚤市场右上角可打开浮窗，设置与助手菜单同步。
- 本地战局可在跳蚤市场直购到背包。超时后自动按原订单重试，同一订单只扣一次卢布。无法放入战局库存的数量会转入系统邮件，客户端收到送达确认后才显示成功。

## 杂项

- 「走私者」默认关闭。启用后可在本地单人战局中超过原生物品带入上限，也可丢弃超过数量限制的非 FIR 物品。
- 修复「走私者」开启后情报等非 FIR 物品仍在丢弃时消失：原实现只覆盖数量检查，实际丢弃另行枚举超限销毁列表。现在对本地单人玩家跳过这份列表，同时保护丢下的背包/容器内的受限物品；不改 FIR，不对已销毁物品做追溯恢复。关闭走私者、战局外、Fika 和其他角色库存继续走原生判断。

- 在「杂项」新增「线上交易」。开启后，本地单人战局中右键点击背包或容器内的物品会显示「新增报价」，可在弹窗内查看市场参考价、选择币种/单价/数量/整包出售并实时试算手续费，上架后从战局中移除对应物品（若同时开启「供不应求」则立即由 Assistant 买下并通过 Ragman 邮件结算）。
- 修复背包和仓库右键菜单的「编辑」在热更新后累积的问题，加载时清理旧版本遗留的按钮。
- 在「杂项」启用「批量售出」可取消跳蚤市场单笔上架的物品数量上限。默认关闭，切换后重新打开上架窗口。

- 在「杂项」启用「自由贸易」可取消跳蚤市场同时在售的挂单数量上限。默认关闭，关闭后恢复按信誉计算的上限，已有挂单继续在售。

## 版本更新与战局时间

- 「战局与物资 → 时间与环境」新增天空调色板。启用天空染色后可选血红等预设，或输入 RGB（0–255）和六位 HEX。颜色会自动保存。

- 在「导航 → 撤离定位」或「视觉 → BTR 站点」打开「地点标记仅显示镜头内」，将撤离点、BTR 站点、追踪物品和传送标记限制在当前镜头视野内。最近模式会选取视野内最近的可用撤离点。

- 本地单人选图时，原生早晚时刻按秒更新，可在读数旁暂停或恢复。已保存的开局时刻用作选图时钟的起点。开局从所选时段继续走时，撤离倒计时独立运行。工厂等固定时刻地图沿用原生读数。
- 在「设置与热键 → 版本更新」点击「选择本地热更新文件」，用 Windows 文件窗口选择解压后的 `Local.Spt5.ESP.Core.module` 或核心 DLL。客户端校验文件并交给现有热更新宿主加载。
- 助手显示的战局剩余时间和游戏 O 键面板共用同一帧的显示秒数，统一在还剩不足一秒时显示 1，到点后显示 0。战局的实际截止时间仍按精确时间计算。

## 射击辅助

- 修复子弹能放入弹匣却不能上膛的问题：兼容范围补上藏身处靶场本地玩家的实际装备实例；原生射击、装填、换弹和故障恢复共用的 IsAmmoCompatible 入口会即时准备目标枪膛，手持武器的 CompatibleAmmo 缓存在两次库存扫描之间持续刷新。保留父容器归属检查与每帧会话缓存，枪膛准备不遍历库存。
- 修复上一版拖动子弹时严重掉帧：兼容检查沿父容器判断归属，不再反复遍历整个库存；联机角色、角色档案和战局状态每帧只读取一次，普通容器的拖拽预览跳过武器兼容准备。
- 修复「弹匣允许混装口径」开启后仍被底层过滤拦截的问题。48558 原生代码会内联弹匣及槽位的兼容检查，现改为挂钩实际共用的物品过滤函数，并覆盖真实的 CompoundItem.Apply 入口。
- 「武器便利」新增独立的「枪膛允许不同口径弹药」，默认关闭。开启后可向自己的枪膛直接装入不同口径普通弹药，并让混装弹匣向枪膛供弹；同步刷新原生 CompatibleAmmo 缓存。转轮弹巢支持这两个开关。
- 两个开关适用于仓库、藏身处靶场和本地单人战局，沿用原生装填、容量、数量拆分和事件流程。每个自有容器使用独立过滤数组，关闭、转移所有权、进入 Fika 或热卸载时恢复原数组；不修改物品模板或弹药口径。
- 验证：EFT 48558 Release 构建、49 项针对性离线回归和 150 组 Probe 检查通过；客户端热更新至 generation 7，payload 哈希匹配且 ready=true。20,000 次检查的性能回归确认旧实现执行 20,000 次库存查询和 40,000 次角色查询，新实现不查询或枚举库存且每帧只查询一次角色；仓库增加 10,000 件物品不增加单次检查工作量。新增回归覆盖独立藏身处档案、扫描前原生供弹、手持武器缓存、卸载不重新注册、同一库存去重及联机/归属边界；旧版在独立藏身处装备场景失败，新版通过。
- 「无限火箭筒」在本地单人战局中支持所有已装填火箭弹的发射器，并沿用设置中的射击间隔。
- 在「射击 → 射击辅助」新增「开镜不抖动」。默认关闭，打开后抑制本地玩家开镜时的呼吸和持枪晃动，与「无后座」独立设置。
- 修复命中提示偶尔把实际扣血显示为 0 的问题。命中提示与准星反馈在命中结算后显示实测扣血，无法读取血量时显示「伤害未记录」。命中和受击提示将小于 0.1 的正扣血显示为 `<0.1`。

## 场景编辑

## 内存编辑器

- 在「反汇编」与「访问监控」新增「列出上下文」弹窗，提供可自由选中复制的上下文文本，支持一键复制全部与导出文件。
- 汇编器支持单代码块标签定义与条件跳转（如 `cmp eax, 0; je skip; ...; skip:`），并支持自动生成带通配符的 AOB 特征码、保存为持久化补丁脚本（`memory-code-patches.json`）及重启后自动重定位应用。
- 新增静态指针反查（Pointer Scan，1–3 级深度、可配置最大偏移）与「结构体剖析（Dissect）」视图（支持基准对比高亮变化字段、指针钻取与上级返回、一键添加到地址表）。
- 优化「内存浏览」十六进制界面：4 字节分组对齐、支持切换 `Hex8 / Int32 / Float / Ptr64` 显示模式、页内字节/UTF-8 搜索、方向键与 `PageUp/PageDown` 翻页、右键复制 16B 特征码与补全 6 种快捷写入类型。
- 修复地址表部分可写页面（`MEM_IMAGE` `.data`、`MEM_MAPPED`、RWX 堆）被误判只读或失效后不更新的问题；地址表新增「无符号」显示、条目类型与指针链原地修改、整表保存/载入（`memory-address-table.json`）与 `F1–F12` 局部热键；扫描支持范围（堆/全部可写/全部可读）、非对齐（1B）与模块/地址区间过滤；访问监控新增暂停刷新与文本过滤。
- 内存浏览器对齐地址按钮、字节和 ASCII 列，窄窗口把数据解析放在网格下方。转到地址后会自动将所选字节滚入视野，也可点击 ASCII 字符选中对应字节。

- 「访问监控」命中快照增加 XMM0–XMM15，可复制完整 128 位值，也可按四个 Float32 查看。顺序执行的指令可右键选「在下一条指令采样」，命中后自动选中记录。采样点是顺序后继的入口，其他路径跳到该入口时也可能命中。
- 汇编输入复用 Iced 的指令形式，支持 `vmovdqu` 的 XMM/YMM 搬运，以及带类型的内存操作数和常见 AVX‑512 掩码、广播写法。编辑框使用 Intel 风格的单条或多条指令，另接受十六进制字节。
- 地址表可添加可读的只读内存，查看数值并启动监控。内存浏览跳转时会显示目标前后的字节，点击行地址或右键字节可重新查看附近内存。
- 右键汇编行可打开该指令已有的寄存器快照。点击快照中的值会尝试浏览对应内存，遇到不可读的值时会复制原值。
- 扫描结果自动刷新当前页的「当前值」，继续筛选仍以扫描时的数值为基准。地址表的数值输入框会跟随读数，手工输入和刚填入的预设会保留。选中扫描结果或地址表一行后按 Del 可移除该行。
- 反汇编先下翻再上翻会回到原页。「转到」支持回车，跳转后按设置显示目标前后的指令，地址栏和高亮都指向目标。状态栏显示实际读到的前后条数，目标不可读时保留当前页。「回退」恢复上一次的目标和上下文。
- 「反汇编」的汇编编辑框支持 AVX 标量浮点加减乘除（如 `vaddss xmm0, xmm1, xmm2`）、XMM/YMM 打包浮点加减乘除和异或、无掩码 ZMM 形式，以及 `vzeroupper`。第三个操作数可用同宽寄存器或匹配尺寸的内存。Windows 独立测试使用 Iced 1.21.0 验证这些指令的编码与反汇编，并检查不匹配的操作数。
- 扫描结束、取消或重置时释放扫描工作缓冲区的引用。清空扫描结果时释放结果列表的底层数组引用。硬件断点的原生异常处理器初始化失败时回收已分配的缓冲区和代码页。
- 在「反汇编 → 实时代码 → 回退步数」设置 0–4096 步，默认 128，0 表示关闭。保存的步数在重启后继续使用。
- 「访问监控 → 查看前导上下文」默认列出命中指令前 128 条、后 64 条，并滚动到高亮的命中指令。在「反汇编 → 实时代码」可分别设置前导和后续条数，各为 0–512 条。「上翻」按指令边界寻找上一页。
- 在「反汇编 → 实时代码」选中一条指令，输入前导和后续条数，点击「导出上下文」，然后用 Windows 窗口选择保存文件夹。导出的 UTF‑8 文本保留地址、机器码和指令，用 `>>` 标出选中行并记录实际导出的前后条数。
- 在「地址表」选中带模块定位的项目，填入目标数值并点击「保存调试值」。重启后打开「调试预设」并点击「填入」，同版本游戏会重新定位模块地址或模块起点的指针链。确认地址后可手动「写入」或「锁定」。预设保存在 MOD 目录中的 `memory-value-presets.json`。
